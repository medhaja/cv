Featured product

Isocline

  • Open source · Apache-2.0
  • Creator & developer

An open-source control plane and durable execution runtime for agent workflows, with a visual builder on top.

The problem
Building an agent is becoming easy; operating agent workflows reliably is not. Model calls fail and rate-limit, workers crash mid-run, approvals take days, side effects need undoing, and generated code has to run somewhere safe.
Who it’s for
Developers and teams who want to compose agent workflows visually and run them on their own infrastructure with any model provider. A Windows desktop build and 53 ready-to-run templates also make it usable by individuals.
My role
I created Isocline and develop it: architecture, runtime, web builder, SDK and CLI, desktop packaging, and release verification.
What it does today
  • Visual builder with typed contracts between nodes, checked before a run starts
  • Durable execution on PostgreSQL: parallel DAGs, crash recovery, checkpoints, rerun from any node
  • Human-in-the-loop waits (approval, timer, callback, event) that hold no worker
  • Saga-style compensation that undoes side effects in reverse order
  • Sandboxed Python in disposable, network-less containers
  • Any model: OpenAI, Anthropic, Gemini, OpenRouter, Ollama and OpenAI-compatible servers
  • MCP tools, RAG on pgvector, webhook and schedule triggers, REST API, Python SDK and CLI
